Support for Skive Run

Skive Run is a free iOS app by Frank Quinn. Email frank.quinn76@163.com.

Four stations run from the neck to the tip. Pare the first station that is not thinner than the one before it. A tip at zero is cut through. Leave it once and the skive runs out. A tip thicker than three still needs the skive carried.

Each strap stays on this iPhone. There is no account and nothing to buy. Questions: frank.quinn76@163.com.

Support for Saw Set

Saw Set is a free iOS app by Alice Harmon. Email alice.harmon54@gmail.com.

A hand saw has teeth that bend left and right. Neighbors must bend opposite ways. Each bend is a number from 0 to 8 on the gauge. Two, three, or four can stay. The sentence names the first tooth that matches its neighbor, then the first tooth that is too light, then the first tooth that is too heavy.

The app does not count the tooth pitch and it does not size the plate. Each saw stays on this iPhone. There is no account and nothing to buy. Questions: alice.harmon54@gmail.com.
